## Summary

Initial implementation of **battery-viz**, a cross-platform Rust desktop app that collects live battery telemetry on macOS and Windows and scores battery health against a research-backed optimization benchmark, rendered with egui on wgpu.

### What's in the PR

- **Collectors** — macOS (`ioreg -r -n AppleSmartBattery -d 1 -a -x` plist parser: cycle count, design/full-charge capacity, temperature in tenths of °C, voltage, charging state) and Windows (`Get-CimInstance Win32_Battery` parser: capacities, design voltage, charge remaining, `BatteryStatus` bits), plus a deterministic simulator for development on any host.
- **Pipeline** — blocking collector on a background thread feeding a bounded crossbeam channel (capacity 4); samples are dropped rather than queued when the UI falls behind, so render latency never inherits collector lag.
- **Benchmark engine** — weighted scoring: SoH 30%, temperature 20%, charge band 15% (20–80% longevity band, 4 pts/% below 20%), high-charge dwell 15%, cycle count 10% (vs. 1000-cycle default limit), charge rate 10% (C-rate while charging, N/A otherwise). Unavailable parameters are excluded with weight renormalization and reported as coverage, never as healthy.
- **Dashboard** — GPU-rendered egui: benchmark ring with grade and coverage, per-parameter scorecard with explanations, live gauges, and 10-minute temperature/power history at 1 Hz.
- **CI** — GitHub Actions workflow running `cargo test --all-targets` on PRs and pushes to `main`.

### Verification

- `cargo test --all-targets`: **18/18 passing, zero warnings** (Linux, simulator collector). Collector paths are fixture-tested; real macOS/Windows hardware verification is follow-up work.
